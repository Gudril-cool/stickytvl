StickyTVL — a durability-adjusted token launch radar. TVL that stays is worth more than TVL that flashes: the board prices each pre-token protocol by a peer multiple (category median FDV/TVL of protocols that already record a token) scaled by how sticky its TVL is, then shows a long-hold farm plan for every row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
